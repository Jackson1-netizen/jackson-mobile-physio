## Configuration — no values in source or reports

Only **Maps JavaScript API** and **PUBLIC_GOOGLE_MAPS_API_KEY** (import.meta.env)
are required. No Map ID, Places, Geocoding, Routes or Directions API.
The browser key is baked into the static build, so deployment variables require a
rebuild. .env.local is gitignored; never print/commit key values or key-bearing URLs.

The loader uses auth_referrer_policy=origin. Configure precise HTTP referrer
origins for the actual hosts used; retain API restriction to Maps JavaScript API.
Local development is port **4721**: http://127.0.0.1:4721 and
http://localhost:4721. Future production canonical is **apex**
https://homemotionphysio.com.au; www is a redirect alias to apex, not primary.
Add only an approved actual preview host, never a bare wildcard or all Netlify hosts.

CSP is generated by scripts/write-netlify-headers.mjs and supports Google's SDK,
tiles, styles/fonts/connections, blob workers and the existing unsafe-eval allowance.
The active map is Google Maps, not the retired Esri implementation.
